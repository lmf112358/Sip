## 1. 背景与问题定义

### 1.1 现状

原项目 Shui 只解决"喝水提醒"一件事，且存在明确的体验问题：

1. **单任务模型**：全局只有一组 `gap / gold / timeStart / timeEnd`，无法同时管理喝水、眼保健操、提肛运动、摸鱼休息。
2. **UI 是后台设置面板**：主窗口直接是设置表单，没有"今天该干什么"的看板，用户打开后不知道该做什么。
3. **提醒形态单一**：全屏页是固定的"喝了么 + 4 个 ml 按钮"，无法换图、换文案、换风格；关掉全屏后也没有"轻提醒"选项。
4. **统计缺失**：只按天存了一个累计 ml 数字（`drink_history_store.json` 的 `{YYYYMMDD: 1200}`），没有次数、没有趋势图、没有各类任务的独立记录，README 里"数据统计"仍是未完成项。
5. **数据不可靠**：`store.json` 键值存储，无法做区间查询与去重，历史数据不可重构。

### 1.2 目标用户

久坐办公的知识工作者（程序员、设计师、运营、学生），一天在电脑前 8–10 小时，需要**被提醒去做那些"知道该做但总是忘"的小事**。

典型特征：
- 注意力被工作占满，主动休息的意志力不足；
- 不喜欢被打断太狠，但"太轻的提醒"又会直接划掉；
- 对"今天做了几次"有模糊的成就感需求（数据反馈 → 习惯维持）。

### 1.3 核心洞察（需求深挖结论）

用户列的四件事：喝水、眼保健操、提肛、摸鱼，本质是**四种不同"打断强度"的任务**，不能用同一套提醒策略：

| 任务 | 心理属性 | 对的提醒方式 | 错的提醒方式 |
| --- | --- | --- | --- |
| 喝水 | 高频、轻量、可量化（ml） | 全屏 / 消息窗，一键记录 | 强制全屏 + 必须点 4 个按钮 |
| 眼保健操 | 需要姿势配合、耗时 1–3 分钟 | 全屏遮罩（必须离开屏幕），带倒计时 | 一条通知，用户直接忽略 |
| 提肛运动 | 极轻、可随时做、略尴尬 | **强伪装**消息窗（旁人看不出在干嘛） | 全屏大字"请做提肛运动" |
| 摸鱼/休息 | 需要"允许自己休息"的心理许可 | 轻提醒 + 可延后（snooze） | 强制全屏打断深度工作 |

**关键产品决策：提醒强度必须是"每任务可配置"的，且伪装能力是提肛这类任务的刚需，不是玩具。**

### 1.4 会议场景（v1.1 新增洞察）

上一版把"白名单应用"当成了会议解决方案，但真实会议远不止"腾讯会议窗口在前台"：

- **面对面会议 / 站着讨论 / 打电话**：电脑可能只是开着，白名单完全检测不到；
- **共享屏幕 / 录屏 / 直播**：一个喝水全屏弹窗会直接出现在参会者面前，社死成本极高；
- **领导临时找你**：需要 0.5 秒内止住所有提醒，没时间进设置页。

**结论：必须有"一键免打扰"，且必须在 3 个地方都能一键触达（主窗、托盘、全局快捷键），而不是藏在设置里。** 这是"焦虑兜底"功能，宁可多一个按钮，也不能让用户在被提醒时手忙脚乱。

进一步分类：会议、专注写代码、临时离开工位，机制完全相同（停止弹窗 + 冻结计时 + 到点自动恢复），只是**语义与预设时长不同**。因此产品上呈现为"会议"这一个显性功能（用户能理解），技术上实现为统一的"免打扰会话"（代码不重复）。

### 1.5 目标与非目标

**目标（v1.0 必须达成）**
- G1 支持 ≥4 类任务并行独立计时，互不干扰，各自独立统计。
- G2 提醒形态可自定义：全屏（含自定义图片/GIF）、消息窗（含伪装样式）、系统通知，按任务独立选择。
- G3 每日使用形成可视化图表（各类任务的次数 / 喝水量）。
- G4 主界面"打开即懂"：3 秒内知道下一次提醒是什么、还剩多久、现在能点什么。
- G5（v1.1）开会 / 面试 / 共享屏幕前，**0.5 秒内**一键静音所有提醒，到点自动恢复。
- G6（v1.2）界面可融入任何桌面环境（深浅主题 + 跟随系统），并支持中英双语切换且**不重启生效**。

**非目标（v1.0 不做）**
- 不做账号体系 / 云同步 / 多设备。
- 不做社交、排行榜、打卡分享。
- 不做移动端（Android/iOS 留接口，不在本期）。
- 不做 AI 生成文案（v1.1 候选）。

## 2. 任务模型（产品核心）

### 2.1 内置任务类型

| 类型 ID | 名称 | 计量单位 | 必填字段 | 默认建议 |
| --- | --- | --- | --- | --- |
| `water` | 喝水 | ml + 次数 | 目标 ml、单次默认 ml | 每 45 分钟，目标 2000ml，单次 250ml |
| `eyes` | 眼保健操 | 次数 | 单次时长（秒） | 每 60 分钟，持续 120 秒 |
| `kegel` | 提肛运动 | 次数（组） | 单次组数 | 每 90 分钟，默认伪装消息窗 |
| `break` | 摸鱼休息 | 次数 + 分钟 | 单次时长 | 每 50 分钟，持续 5 分钟 |
| `custom` | 自定义 | 次数 | 名称、图标、间隔 | — |

### 2.2 任务字段定义

```
名称 name            用户可改的显示名（如"喝口水""做组提肛"）
类型 type            water | eyes | kegel | break | custom
启用 enabled         独立开关
间隔 intervalMin     上一次"完成/跳过"后到下一次提醒的分钟数
活跃时段 activeTime  时间段 09:00–18:00，支持跨天（22:00–02:00）
生效星期 weekdays    0–6，默认周一至周五
提醒样式 remindStyle fullscreen | toast | system
提醒模板 templateId  指向模板库，可为每任务单独指定
提示音 sound         内置音效 / 静音 / 自定义文件
允许延后 snoozeMin  0 = 不允许；>0 = 显示"稍后 N 分钟"
目标 goal            water: ml 目标；其他: 次数目标（可空 = 不设目标）
单次值 unitValue     water: 每次默认 ml；eyes/break: 秒；kegel: 组
每日上限 cap         超过后当日不再提醒（防打扰）
```

### 2.3 计时规则（必须精确，验收重点）

1. **每个任务独立计时**：任务 A 被延后不影响任务 B。
2. **计时基准是"上次确认时刻"**：用户点"我喝了/做完了"或"跳过"或"稍后"时，倒计时从该时刻重新开始。
3. **并发冲突处理**：同一时刻多个任务到期时，按优先级串行弹出（`water > eyes > kegel > break > custom`），间隔 3 秒；同类只弹一次。
4. **暂停场景**（任一成立即暂停所有任务计时，恢复后继续，不补弹）：
   - 系统锁屏 / 休眠（复用原项目 `monitor_lock_screen`）；
   - 前台应用命中白名单（默认：腾讯会议、Zoom、Teams、钉钉会议、OBS）；
   - 用户手动"专注模式"N 分钟。
5. **跨天处理**：活跃时段跨 00:00 时，按"当天开始日期"归属统计。
6. **错过补偿**：电脑休眠 2 小时后唤醒，只提醒一次，不连环弹 N 次。

## 3. 功能需求

### F1 今日看板（P0）

主窗口首页。信息层级由上到下：

0. **顶部工具条**：左侧问候与日期；右侧常驻「🎧 会议模式」按钮（点击展开 15/30/45/60 分钟/不限时长），会议中变为红色横幅。
1. **顶部大卡**：当前最近的一次提醒 —— 任务图标、任务名、"还有 12:34"、进度环（已用/间隔），以及一个超大主按钮（`我喝了 250ml` / `我做完了` / `我休息好了`）。
2. **任务卡列表**：每个启用任务一行卡片，含实时倒计时、今日完成 `3/8`、`跳过`、`稍后`（若允许）、`立即提醒`。
3. **今日概览条**：喝水 x 次 / xx ml、眼保健操 x 次、提肛 x 组、摸鱼 x 分钟。
4. **底部**：下次提醒时间点预览（"14:35 喝水 · 15:10 眼保健操"）。

**验收**
- 倒计时与真实时钟误差 ≤ 1 秒，切到别的页面再回来不重置。
- 完成操作后 200ms 内反馈（按钮按压 + 进度环动画 + 数字 +1）。
- 关闭窗口不退出程序，驻留托盘（沿用原项目行为）。

### F2 多任务管理（P0）

任务列表页 + 任务编辑弹层。支持：新增（从 4 个模板一键创建）、编辑、启用/停用、删除、拖拽排序（v1 用上/下按钮代替拖拽）。

**验收**
- 任一字段修改后，调度器在 1 秒内生效，倒计时按新间隔重算（从修改时刻起算）。
- 至少可同时运行 5 个任务无卡顿。
- 删除任务时二次确认，历史记录保留（统计中仍可见）。

### F3 提醒形态可自定义（P0，核心差异化）

#### F3.1 全屏提醒
- 覆盖所有显示器（复用原项目多屏窗口逻辑），`always_on_top` + 无边框 + 可 Esc 关闭。
- 背景：纯色 / 渐变 / **本地图片 / GIF**（用户上传，复制到应用数据目录，避免路径失效）。
- 内容：大图标、主标题、副标题、可选操作按钮组、倒计时自动关闭（默认 30 秒，可关）。
- 透明度遮罩可调（0–90%），避免全屏过亮刺眼。

#### F3.2 消息窗提醒（伪装）
- 屏幕右下角浮窗，不抢焦点、不遮全屏、5 秒后可自动消失。
- 内置伪装皮肤（**自绘风格，不使用任何第三方官方素材与商标**）：
  - `chat`：仿聊天软件消息气泡（头像 + 名称 + 消息 + "回复"入口），名称/头像/文案全部用户可改，默认"工作群 · 小李"；
  - `mail`：仿邮件客户端新邮件通知；
  - `system`：仿系统更新提示；
  - `minimal`：极简胶囊（只显示图标 + 一句文案）。
- 点击浮窗 = 记为完成；长按/右键 = 跳过。
- 支持"防窥模式"：鼠标悬停时才显示真实任务名，默认显示伪装文案。

#### F3.3 系统通知
- 调系统原生通知（沿用 `tauri-plugin-notification`），适合摸鱼/后台场景。

**验收**
- 三种形态可按任务独立设置且互不影响。
- 用户上传 GIF 后重启应用仍生效，文件缺失时降级为默认渐变背景并提示。
- 消息窗不夺取键盘焦点（打字时弹窗不会打断输入）。

### F4 数据与统计（P0）

- 记录粒度：**每一次交互一条记录**（`complete` / `skip` / `snooze`），带任务、类型、值（ml / 次 / 秒）、时间戳。
- 统计页：
  - **今日环形图**：各任务完成度（如喝水 1200/2000ml）；
  - **近 7 / 30 天趋势**：折线/柱状，可切换指标（喝水 ml、喝水次数、各类次数）；
  - **时间分布热力**：一天 24 小时里哪个时段完成最多（帮助发现自己的节奏）；
  - **连续天数（streak）**：达成目标的连续天数；
  - **汇总卡**：本周总次数、平均间隔、跳过率。
- 数据保留：默认永久；提供"清空数据"与"导出 CSV"。

**验收**
- 图表数据与原始记录一致（抽查任意一天，次数/数值对得上）。
- 切换 7/30 天即时重算，≤ 300ms。
- 卸载/升级不丢数据（存 `app_data_dir`）。

### F5 设置（P0，v1.2 提级）

设置分 6 组，纵向分组 + 每组一个标题，不做二级导航（窗口只有 4 个页面，二级导航是过度设计）。

| 分组 | 项 |
| --- | --- |
| 外观 | 主题（深色 / 浅色 / 跟随系统）、强调色（4 选 1）、界面缩放（90% / 100% / 110%） |
| 语言 | 中文 / English / 跟随系统 |
| 通用 | 开机自启、关闭即最小化到托盘、托盘显示倒计时、默认提醒音与音量 |
| 免打扰 | 全局免打扰时段、白名单应用管理、会议模式默认时长 |
| 提醒模板 | 管理自定义模板（新建 / 复制 / 编辑 / 预览 / 删除） |
| 数据 | 导出 CSV、清空数据、打开数据目录 |
| 关于 | 版本号、检查更新、开源许可 |

**验收**：任一项修改后立即生效，无需重启、无需点"保存"。

### F6 托盘与快捷键（P1）

- 托盘左键：显示主窗口；右键菜单：今日概览（静态文本）、暂停 30 分钟、专注模式、退出。
- 托盘标题倒计时：显示**下一个到期任务**的剩余时间（原项目只显示单一任务）。
- 全局快捷键：`Cmd/Ctrl+Shift+H` 唤起主窗口；提醒出现时 `Esc` 关闭。

### F7 引导（P2）

首次启动 3 步引导：选任务（默认勾选喝水 + 眼保健操 + 提肛 + 摸鱼）→ 设时段 → 选提醒风格，30 秒内可用。

### F8 会议模式（P0，v1.1 新增）

**定位**：一键全量静止。不是"降低打扰"，是"完全不打扰"。

#### 入口（三处，必须都在）

| 位置 | 交互 |
| --- | --- |
| 主窗口顶部 | 常驻「🎧 会议模式」按钮，点击展开时长选择（15 / 30 / 45 / 60 分钟 / 不限 / 到明天 09:00），记住上次选择 |
| 托盘右键菜单 | `开启会议模式 ▸` 子菜单同预设，一键生效无需开窗 |
| 全局快捷键 | `Ctrl/Cmd + Shift + M`，按下即用上次时长开启；再按 = 结束 |

#### 会议中的行为（逐条可验收）

1. **立即静默**：已有的全屏提醒窗立刻关闭；消息窗立刻隐藏；未发出的系统通知取消。
2. **完全冻结**：所有任务 `next_due` 停止推进（剩余时间不变），不弹窗、不发声、不写 skip。
3. **状态可见**：托盘图标叠加一个静音角标；托盘菜单第一行显示 `会议中 · 剩 12:34`；主窗口顶部变为红色横幅 `会议中，还有 12:34 · 结束会议`。
4. **仍可手动记录**：任务卡变暗但"我喝了/我做完了"仍可点（用户真的喝了要能记），记录照常入统计。
5. **结束前预告**：剩余 3 分钟时托盘 tooltip 变为 `3 分钟后恢复提醒`。
6. **到点自动恢复**：会话结束 → 计时从冻结值继续 → 进入 **60 秒软着陆**（60 秒内不弹任何提醒，避免"刚散会就被弹"）。
7. **软着陆后补一条**：托盘/主窗提示"会议结束，下次提醒 12:34 后"。

#### 防"忘记关闭"（关键安全阀）

- **不限时长**模式下，每 2 小时托盘弹一次气泡：`会议模式已开 2 小时，要结束吗？`（点气泡直接结束）。
- **应用重启视为会议结束**：重启后一律恢复提醒（否则"不限时长"会让用户永久静音而不自知），主窗轻提示"上次会议模式已结束"。
- 托盘静音角标持续可见，是一眼能发现的兜底。

#### 记录与统计

- 会议时长写入 `sessions` 表（`kind=meeting`），统计页显示「本周会议 6.5 小时」。
- 会议期间不产生 `skip` 记录，**跳过率分母不含会议时段**（否则统计失真）。

**验收**
- 按快捷键到全屏静默 ≤ 300ms。
- 会议 30 分钟结束，30 分钟内任一任务剩余时间与开启前**完全一致**（冻结而非清零）。
- 开着会议模式重启应用 → 提醒正常恢复，无永久静音。
- 会议中点"我喝了 250ml"→ 记录成功，今日 ml +250，但计时仍冻结。

### F9 托盘快速记录（P1，v1.1 新增）

- 托盘右键菜单第一块：`💧 喝水 +250ml`、`✅ 眼保健操完成`，点一下即记录，不打开主窗口。
- 菜单里以不可点击文本显示今日进度：`今日 750/2000ml · 3 次`。
- 理由：开会前、离开工位这些瞬间不值得开窗，但记录不能丢。

### F10 体验细节（P1，v1.1 补强）

| 项 | 设计 | 价值 |
| --- | --- | --- |
| 持续型任务倒计时 | 眼保健操/摸鱼/提肛这类有"单次时长"的任务，全屏页显示大号圆形倒计时（120s → 0），结束自动记为完成并关闭 | 原设计只写"持续 120 秒"，但没定义用户怎么知道做够了 |
| 音效渐入 | 提醒音 1.5 秒内从 0 线性升到设定音量（默认 60%） | 突然大音量是"提醒软件被卸载"的第一原因 |
| 提示音量与静音 | 全局音量滑杆 + 一键静音；每任务可单独选音效或静音 | — |
| 目标推荐 | 设置页填体重 → 按 30ml/kg 推荐每日目标（一键采用） | 减少"目标填多少"的决策成本 |

### F11 主题系统（P0，v1.2 新增）

**三态切换**：深色 / 浅色 / 跟随系统（默认"跟随系统"，首次启动即读 `prefers-color-scheme`）。

#### 为什么不能简单"反色"

浅色主题不是把深色主题的颜色对调。任务色在深色底上够亮，放到白底上对比度会掉到 3:1 以下（不符合无障碍要求），必须**整体加深一级**：

| 任务 | 深色主题 | 浅色主题 | 白底对比度 |
| --- | --- | --- | --- |
| 喝水 | `#38BDF8` | `#0284C7` | 4.6:1 ✓ |
| 眼保健操 | `#34D399` | `#059669` | 4.8:1 ✓ |
| 提肛 | `#A78BFA` | `#7C3AED` | 5.1:1 ✓ |
| 摸鱼 | `#FBBF24` | `#D97706` | 4.5:1 ✓ |

#### 生效范围

| 区域 | 是否跟随主题 | 说明 |
| --- | --- | --- |
| 主窗口 | 是 | 全部卡片、文字、按钮 |
| 全屏提醒页 | 部分 | 背景由模板决定（图片/渐变），但**文字与按钮恒为浅色系 + 暗色蒙层**，避免浅色图配深色字看不清 |
| 消息窗（伪装皮肤） | 独立 | 伪装皮肤自带配色（仿聊天软件就是要像它），不跟随主题 |
| 托盘图标 | 是 | 深色任务栏用浅色图标变体（`icon-tray-light.ico`），浅色任务栏用深色变体 |
| 系统通知 | 否 | 由操作系统渲染，不可控 |

#### 强调色（4 选 1）

`accent` 只影响**非任务类**的界面元素（导航选中态、聚焦环、会议按钮、输入框光标），任务色固定不变 —— 否则用户换了强调色，四个任务的区分色就崩了。

预设：`ocean #38BDF8`（默认）/ `violet #A78BFA` / `emerald #34D399` / `amber #FBBF24`。

#### 验收

- 切换主题 ≤ 100ms 全局生效，无闪白、无闪烁。
- 选择"跟随系统"后，在 OS 里切换深/浅色，应用**实时**跟随（无需重启、无需切页面）。
- 三处窗口（主窗 / 全屏 / 消息窗）同一时刻不会出现主题不一致。
- 浅色主题下所有正文文字对比度 ≥ 4.5:1（可用浏览器 DevTools 抽查）。

### F12 中英双语（P0，v1.2 新增）

**三态**：中文 / English / 跟随系统（默认跟随 `navigator.language`，`zh*` → 中文，其余 → English）。

#### 覆盖范围（必须全覆盖，不能有中文残留）

| 位置 | 示例 |
| --- | --- |
| 全部界面文案 | 按钮、标题、空状态、错误提示、设置项说明 |
| 内置提醒模板 | `该喝水了` → `Time for water` |
| 内置任务默认名 | 喝水 / 眼保健操 / 提肛 / 摸鱼 → Water / Eye exercise / Kegel / Break |
| 托盘菜单与 tooltip | `开启会议模式` → `Start meeting mode` |
| 系统通知 | 标题与正文 |
| 日期与时间格式 | 中文 `10月27日 周二` → 英文 `Tue, Oct 27` |
| 单位 | `次 / 组 / 分钟` → `times / sets / min`（`ml` 不变） |

**不覆盖**：用户自己起的任务名、自定义模板文案、伪装皮肤里用户填的人名/群名 —— 用户输入的内容原样保留，不能"翻译"。

#### 内置任务名的语言切换（技术约束）

数据库里**不能**存死中文名。内置任务存 `nameKey`（如 `task.water`），显示时按当前语言查词典；只有用户手动改过名字，才存用户输入的字面值。这样切换语言时，用户没改过名的任务会自动变成英文，改过名的保持原样。

#### 英文布局约束（真实风险）

英文文案平均比中文长 **40%–60%**（`我喝了 250ml` → `I drank 250 ml`）。因此：

- 主按钮文字允许 2 行，行高固定，不做 `ellipsis` 截断动作词；
- 次级动作（跳过 / 稍后）在英文下允许换行排布，不压缩到 11px；
- 卡片最小宽度按最长英文文案定，不用中文宽度反推；
- 侧边导航在英文下加宽 24px；
- 单条文案长度上限：中文 ≤ 12 字，英文 ≤ 34 字符，超出必须改文案而不是调字号。

**验收**
- 切换语言后，页面上**找不到任何中文残留**（除用户输入内容）。
- 托盘菜单、系统通知同步切换。
- 英文界面下逐页检查：无文字截断、无按钮文字溢出、无布局错位。

## 4. 交互流程图

```
启动
 ├─ 首次 → 引导（选任务 → 时段 → 风格）→ 写库 → 后台调度线程启动
 └─ 非首次 → 主窗口（今日看板）→ 最小化到托盘

调度线程（1s tick）
 ├─ 暂停条件成立（会议模式 / 锁屏 / 白名单 / 专注 / 免打扰 / 非活跃时段 / 超上限）
 │        → 冻结，托盘显示"会议中"或"暂停"
 └─ 到期 → 按优先级排队 → 按任务 remindStyle
        ├─ fullscreen → 每屏创建全屏窗 → 用户点按钮 / Esc / 自动倒计时
        ├─ toast      → 右下角伪装窗 → 点击=完成，右键=跳过
        └─ system     → 系统通知
      → 任一动作写 records → 重置该任务计时 → 刷新统计

会议模式（任意入口触发）
 ├─ 记录 sessions(kind=meeting, planned_min)
 ├─ 关闭已弹出的全部提醒窗 → 冻结所有计时 → 托盘加静音角标
 ├─ 剩余 3 分钟 → 托盘预告
 └─ 到点 → 解除冻结 → 60 秒软着陆 → 正常调度
```

## 附录 B v1.3 变更详情（2026-10-27 评审后）

> 完整评审推理过程见 `需求评审-v1.3.md`。此节只记录**定稿结论**，作为开发依据。
> 四条决策已由用户确认：① 安静时段全局最多 3 条；② 回座 60 秒缓冲；③ 首页「立即提醒」改为「预览提醒」；④ 会议中一律屏蔽（不做喝水放行开关）。

### B.1 F13 安静时段（替代原「免打扰」）

**为什么要拆出来**：原设计的「免打扰」与用户口中的「午休」是同一个机制，但只有一条时段、且没有"结束后怎么处理"的表达能力。v1.3 把它升格为**作息层**。

| 项 | 规则 |
| --- | --- |
| 作用范围 | **全局**，与任务无关；最多 **3 条** |
| 每条字段 | 开始时间、结束时间（支持跨零点）、生效星期、**回座行为**（立刻提醒 / 60 秒后提醒） |
| 语义 | 活跃时段 ∩ 非安静时段。安静时段内：不计时（`next_due += 1s`）、不提醒、不写 `skip` 记录、不影响跳过率 |
| 回座缓冲 | 安静时段结束瞬间若任务已到期，按该条时段的「回座行为」处理；默认 **60 秒后提醒** |
| 与会议的关系 | 会议优先级更高（0 级），安静时段为 5 级；两者都冻结，但会议期长、安静时段按天循环 |
| 默认值 | 首次启动预置一条 `12:00–13:30 周一~周五 回座 60 秒` |

**验收**
1. 12:00 时水任务剩 3 分钟 → 13:30 安静时段结束后，剩余仍是 3 分钟（不重置为 45 分钟、不补发 3 次）。
2. 安静时段内 `records` 表零新增。
3. 跨零点时段（22:30–08:00）正常冻结。
4. 60 秒缓冲期间首页显示"60 秒后恢复提醒"。

### B.2 F1 首页重构

原来的首页有计时（圆环倒计时）和进度（3/8 次），但**没有记录**：用户看不到今天几点做了什么。v1.3 补上。

**三层结构**

| 层 | 内容 |
| --- | --- |
| 头 | 问候 + 日期 + **会议常驻开关**（超时显示已持续时长） |
| 主卡 | 圆环倒计时 + `12:34 后提醒`；右侧 `今日 3 次 · 750/2000 ml`；74px 主按钮「完成一次」；小链接 **跳过 / 稍后 N 分钟 / 预览提醒** |
| 今日记录 | 新增卡片：当日流水时间轴（`14:02 喝水 250ml ✓`），每行可长按/点开修改或删除；默认显示 6 条，可展开 |
| 全部任务 | 每个卡片补 `今日 N 次 · 下次 12:34`——**记录与计时并排** |

**「立即提醒」→「预览提醒」**：原入口点击无反应（根因三选一：窗口复用事件丢失 / 浏览器 mock 未接管 / 任务行本身不可点），且语义与主按钮重复。改为**预览**，复用同一套渲染，预览窗 5 秒自动关闭，不影响任何计时与记录。

**新增命令**：`today_records(limit)` 返回当日明细（时间 / 类型 / 动作 / 数量 / id），支持 `delete_record(id)`。

### B.3 F8 会议模式改「常驻」

| 项 | v1.2 | **v1.3** |
| --- | --- | --- |
| 入口形态 | 下拉选时长（15/30/45/60/不限/到明天） | **单个常驻开关**：点一下开，再点一下关 |
| 时长 | 必选 | 默认不限（无 `ends_at`）；15/30/60 仅保留在托盘菜单 |
| 防遗忘 | 满 2 小时弹系统通知 | **取消弹窗**。改：托盘图标 `●` 前缀 + 首页横幅 `● 会议模式已持续 2h 12m · 结束` |
| 屏蔽范围 | 全部任务 | **全部任务，含喝水**（用户明确要求，不做放行开关） |
| 重启 | 视为结束 | 不变，首页提示"上次会议模式已随重启结束" |

**理由**：常驻的语义是"别烦我"，2 小时弹窗本质仍是打扰。防遗忘改为"只在你主动看它时出现"。

### B.4 F14 提醒个性化（设置内独立分区）

**解决的核心冲突**：此前提醒配置分散在「任务」（`remind_style` / `template_id`）和「设置」（全局 `fullscreenImage`）。若两边都能改，用户改完设置不生效是必然。

**优先级规则**

> 设置里的「提醒」= **按任务类型的默认值**；任务内可选「跟随默认」或显式覆盖。
> 任务编辑器中的提醒方式默认显示为「跟随默认（全屏）」，一眼可见当前生效值。

**四个子块**

| 子块 | 内容 |
| --- | --- |
| ① 形态与节奏 | 按类型设默认形态（全屏/消息窗/系统通知）；全屏持续秒数（或"必须交互"）；消息窗停留秒数；延后档位 5/10/15 |
| ② 外观 | 全屏背景（8 套渐变预设 / 自定义图片 / GIF / 文件夹轮播）、遮罩浓度、背景模糊、是否显示倒计时、文案模板（9 套 + 自定义）；消息窗皮肤（微信/邮件/系统/极简）+ 四角位置；微信皮肤可填发送人昵称、头像文字、正文 |
| ③ 声音 | 音效 3 选 / 关闭、音量、渐入时长、会议与专注中静音 |
| ④ 预览 | 每种形态一个「预览」按钮（全屏 5 秒自动退出、消息窗 3 秒） |

**收敛原则**：默认只展开四行摘要（"默认全屏 · 12 秒 · 8 套背景 · 预览"），详细参数折叠在「更多」里，避免配置项淹没"简单明了"。

**数据结构**：`Settings.fullscreenImage: String` 升级为 `Settings.reminder: { [type]: RemindProfile }`，`RemindProfile = { style, templateId, durationSec, toastSkin, toastPos, sound, volume, bgImage, dim, blur }`；任务级同名字段留空 = 跟随默认。
